# Local App - Capstone Prototype

A modern Flutter mobile application built with Firebase authentication, dynamic theming, and clean architecture. This is the official **Capstone Prototype** for the project.

## ✨ Features

- **Firebase Authentication** integration
- **Light & Dark Theme** support with persistent theme switching
- **Secure Routing** with authentication state management
- **Stream-based Auth Checker** – automatically redirects users based on login status
- Beautiful and responsive UI using Material Design
- Structured codebase with proper separation of concerns
- Comprehensive logging for debugging

## 🛠 Tech Stack

- **Flutter** (Dart)
- **Firebase** (Core + Authentication)
- **Provider** (State Management)
- **Logger** (Pretty logging)
- Custom Router & Theme Management
